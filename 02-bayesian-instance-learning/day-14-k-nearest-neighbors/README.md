# Day 14 — K-Nearest Neighbors (KNN)

**Module:** Module 3: Bayesian and Instance-Based Learning

## Theory

- Instance-based and lazy learning.
- Distance functions: Euclidean, Manhattan, and Minkowski.
- Choosing k and the effect of small vs. large k.
- Distance-weighted KNN.
- Feature scaling, high-dimensional data, and the curse of dimensionality.

## Practical

- Implement KNN classification with scikit-learn.
- Compare different values of k.
- Compare Euclidean and Manhattan distance.
- Examine how scaling features changes the results.

## Outcome

Learners can explain how a prediction is based on nearby training examples and why scaling matters.
