# Day 13 — Bayesian Belief Networks

**Module:** Module 3: Bayesian and Instance-Based Learning

## Theory

- What is a Bayesian Belief Network (BBN)?
- Directed acyclic graphs (DAGs).
- Nodes, directed edges, conditional probability tables.
- Conditional independence and probabilistic inference.
- Bayesian networks vs. Naive Bayes.
- Practical applications in diagnosis, risk analysis, and decision support.

## Practical

- Draw a simple network: Rain -> Wet Grass, with Sprinkler -> Wet Grass.
- Define conditional probabilities.
- Calculate the probability of wet grass given evidence.
- If time permits, demonstrate inference using a Bayesian-network library.

## Outcome

Learners can represent dependencies between variables and explain probabilistic reasoning.
