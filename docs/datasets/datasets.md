# Datasets

Built-in and educational datasets used throughout the course.

- Iris: classification examples
- California Housing: regression examples
- Breast Cancer Wisconsin: binary classification
- Digits/Wine: multiclass classification
- Customer churn: end-to-end and deployment projects
- Titanic: preprocessing and pipeline examples
- Mall Customers: clustering examples

 Prefer scikit-learn built-in datasets for reproducibility; download large datasets only when needed.
