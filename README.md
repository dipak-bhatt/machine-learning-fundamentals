# machine-learning-fundamentals

Hands-on Machine Learning course with 24 day-wise lessons, supporting documentation, and end-to-end projects.

## Course Structure

- `docs/setup/` - environment setup guides
- `docs/datasets/` - dataset references
- `docs/references/` - learning references
- `00-foundations/` - Days 01-04
- `01-supervised-learning/` - Days 05-11
- `02-bayesian-instance-learning/` - Days 12-14
- `03-unsupervised-learning/` - Days 15-17
- `04-evaluation-and-optimization/` - Days 18-20
- `05-modern-ml-and-project/` - Days 21-24
- `projects/` - practical ML projects

## Days

00-foundations
- Day 01 - Introduction to ML
- Day 02 - Data, Statistics, Probability
- Day 03 - Training, Validation, Testing
- Day 04 - Bias, Variance, ML Workflow

01-supervised-learning
- Day 05 - Linear Regression
- Day 06 - Gradient Descent, Feature Engineering
- Day 07 - Logistic Regression
- Day 08 - Perceptron, Neural Networks
- Day 09 - Decision Trees
- Day 10 - Support Vector Machines
- Day 11 - Ensemble Learning

02-bayesian-instance-learning
- Day 12 - Bayes Theorem, Naive Bayes
- Day 13 - Bayesian Belief Networks
- Day 14 - K-Nearest Neighbors

03-unsupervised-learning
- Day 15 - K-Means Clustering
- Day 16 - Hierarchical Clustering, DBSCAN
- Day 17 - PCA, Dimensionality Reduction

04-evaluation-and-optimization
- Day 18 - Classification Metrics
- Day 19 - ROC, Cross Validation
- Day 20 - Pipelines, Hyperparameter Tuning

05-modern-ml-and-project
- Day 21 - End-to-End ML Pipeline
- Day 22 - Deep Learning, Modern AI
- Day 23 - Model Deployment, API
- Day 24 - Capstone Project

## Getting Started

1. Create and activate a Python virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Follow the day folders in order.
