# Day 16 — Hierarchical Clustering and Modern Clustering

**Module:** Module 4: Unsupervised Learning

## Theory

- Agglomerative and divisive hierarchical clustering.
- Dendrograms and linkage methods.
- Distance metrics and their influence on clusters.
- DBSCAN as a modern extension.
- Density-based vs. centroid-based clustering.
- Using clustering before a supervised learning task, and the risks of leakage.

## Practical

- Generate a dendrogram and compare linkage methods.
- Apply hierarchical clustering and DBSCAN.
- Test on data containing irregularly shaped clusters and noise.
- Discuss how customer segmentation could support a later prediction model.

## Outcome

Learners can choose between K-means, hierarchical clustering, and DBSCAN based on the data's structure.
