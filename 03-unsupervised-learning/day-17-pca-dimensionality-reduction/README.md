# Day 17 — Dimensionality Reduction and PCA

**Module:** Module 4: Unsupervised Learning

## Theory

- The curse of dimensionality.
- Feature selection vs. feature extraction.
- Dimensionality reduction and its benefits.
- Principal Component Analysis (PCA).
- Standardization, covariance, eigenvectors, and eigenvalues at an introductory level.
- Explained variance and information loss.
- Limitations of PCA: interpretability and nonlinear structures.

## Practical

- Standardize a dataset.
- Apply PCA and plot the first two principal components.
- Examine explained-variance ratios.
- Compare a classifier trained on original features with one trained on reduced features.

## Outcome

Learners can reduce the number of features and explain the tradeoff between dimensionality and retained information.
