# House Price Prediction

Goal: Predict numerical house prices using regression.

Dataset: California Housing or a small housing CSV.

Tasks:
- Load and explore the dataset.
- Train a baseline linear regression model.
- Compare with Ridge regression.
- Evaluate using MAE, RMSE, and R-squared.
- Save the best model with joblib.

Run:
```bash
python projects/house-price-prediction/train.py
```
