# Day 08 — Perceptron and Neural Network Fundamentals

**Module:** Module 2: Supervised Learning

## Theory

- Artificial neuron, weights, bias, and activation functions.
- Perceptron learning rule.
- Linearly separable vs. non-linearly separable data.
- Input, hidden, and output layers.
- Forward propagation, loss, and backpropagation at a conceptual level.
- Introduction to deep learning and when it is useful.

## Practical

- Implement a perceptron using NumPy.
- Train it on simple linearly separable data.
- Demonstrate why a single perceptron cannot solve XOR.
- Build a small neural network using scikit-learn's MLPClassifier or a framework such as PyTorch.

## Outcome

Learners understand the bridge between classical ML and neural networks.
