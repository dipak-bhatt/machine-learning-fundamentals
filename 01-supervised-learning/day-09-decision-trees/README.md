# Day 09 — Decision Trees

**Module:** Module 2: Supervised Learning

## Theory

- Decision tree representation.
- Appropriate problems for decision trees.
- Root nodes, internal nodes, leaves, and splitting rules.
- Entropy, information gain, and Gini impurity.
- Basic decision tree learning algorithm.
- Pruning, maximum depth, and overfitting.

## Practical

- Train a decision tree classifier.
- Visualize the learned tree.
- Change maximum depth and compare performance.
- Explain a prediction using its decision path.

## Outcome

Learners can explain and interpret a tree-based model.
