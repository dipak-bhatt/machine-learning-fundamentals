# Day 06 — Regression Optimization and Feature Engineering

**Module:** Module 2: Supervised Learning

## Theory

- Cost/loss functions and why errors are squared in least-squares regression.
- Introduction to gradient descent.
- Learning rate and convergence.
- Multiple features, feature scaling, and multicollinearity.
- Polynomial regression as a way to model nonlinear relationships.
- Introduction to regularization: Ridge and Lasso.

## Practical

- Implement a simple gradient-descent update in NumPy.
- Compare linear and polynomial regression.
- Compare ordinary regression with Ridge regression.
- Observe how feature scaling affects optimization.

## Outcome

Students understand how a model's parameters are learned and how feature choices affect predictions.
