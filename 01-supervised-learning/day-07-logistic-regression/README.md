# Day 07 — Logistic Regression and Classification

**Module:** Module 2: Supervised Learning

## Theory

- Binary and multiclass classification.
- Logistic regression and the sigmoid function.
- Probability estimates, decision boundaries, and classification thresholds.
- Log loss and the difference between regression and classification.
- Multiclass classification strategies.

## Practical

- Predict whether a tumor is benign or malignant using an educational dataset.
- Train logistic regression with scikit-learn.
- Inspect predicted probabilities.
- Change the classification threshold and observe how predictions change.

## Outcome

Students can build a classification model and explain how predicted probabilities become class labels.
