# Day 10 — Support Vector Machines (SVM)

**Module:** Module 2: Supervised Learning

## Theory

- Separating hyperplanes and decision boundaries.
- Maximum-margin classification.
- Support vectors and margin width.
- Linear vs. nonlinear classification.
- Kernel trick: linear and RBF kernels.
- Feature scaling and SVM limitations.

## Practical

- Train linear and RBF SVM classifiers.
- Visualize decision boundaries using two features.
- Compare results with logistic regression.
- Explore the effect of the regularization parameter C and kernel settings.

## Outcome

Students understand maximum-margin classification and when kernels are useful.
