# Day 20 — Preprocessing, Hyperparameter Tuning, and Responsible ML

**Module:** Module 5: Evaluation and Optimization

## Theory

- Data preprocessing pipelines.
- Missing-value imputation, categorical encoding, and feature scaling.
- Feature selection and feature engineering.
- Hyperparameters vs. learned parameters.
- Grid search and randomized search.
- Data leakage, class imbalance, and resampling.
- Fairness, privacy, explainability, and responsible use of predictions.

## Practical

- Build a scikit-learn Pipeline and ColumnTransformer.
- Use cross-validation with GridSearchCV or RandomizedSearchCV.
- Compare tuned and untuned models.
- Demonstrate how preprocessing the entire dataset before splitting can leak information.

## Outcome

Students can construct a reproducible training workflow and tune models without contaminating evaluation data.
