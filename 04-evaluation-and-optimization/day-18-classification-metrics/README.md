# Day 18 — Classification Evaluation Metrics

**Module:** Module 5: Evaluation and Optimization

## Theory

- Confusion matrix: TP, TN, FP, and FN.
- Accuracy and misclassification costs.
- Sensitivity/recall, specificity, precision, and F1-score.
- Precision-recall tradeoffs.
- ROC curve and ROC-AUC.
- Choosing metrics based on the problem and class imbalance.

## Practical

- Calculate each metric from a confusion matrix by hand.
- Evaluate a classifier using scikit-learn.
- Compare accuracy and recall on an imbalanced dataset.
- Change the threshold and examine its effect on false positives and false negatives.

## Outcome

Students can choose appropriate metrics instead of relying on accuracy alone.
