# Day 22 — Deep Learning and Modern AI Overview

**Module:** Module 6: Modern ML and Project

## Theory

- Traditional ML vs. deep learning.
- Multilayer neural networks, activation functions, loss functions, and backpropagation.
- Epochs, batches, learning rate, and optimizers.
- CNNs for images and sequence models for text or time series.
- Transformers and large language models (LLMs): a high-level introduction.
- Generative AI vs. predictive ML.

## Practical

- Train a small neural network on a tabular dataset or use a simple image-classification dataset.
- Compare its performance with a classical ML model.
- Demonstrate a pretrained model or an LLM-powered application concept.
- Discuss computational cost, data requirements, and limitations.

## Outcome

Learners understand where deep learning and generative AI fit into the broader ML landscape.
