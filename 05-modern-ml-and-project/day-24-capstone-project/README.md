# Day 24 — Capstone Demonstration, Review, and Assessment

**Module:** Module 6: Modern ML and Project

## Theory

- Review the complete ML workflow.
- Select algorithms based on the problem and dataset.
- Explain evaluation metrics and model limitations.
- Common mistakes: leakage, overfitting, inappropriate metrics, and unreliable test results.
- Communicate results to technical and nontechnical audiences.

## Practical

- Student presentations and live demonstrations.
- Review source code, preprocessing, model selection, and evaluation.
- Run predictions on previously unseen examples.
- Peer review and instructor feedback.
- Short individual viva or conceptual assessment.

## Outcome

Each student or group can explain, demonstrate, and defend a complete ML project.
