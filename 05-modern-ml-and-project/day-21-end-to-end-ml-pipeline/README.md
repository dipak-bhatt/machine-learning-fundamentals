# Day 21 — End-to-End ML Pipeline

**Module:** Module 6: Modern ML and Project

## Theory

- The full ML lifecycle: problem definition, data collection, preprocessing, training, evaluation, and prediction.
- Baseline models and why simple solutions matter.
- Reproducible experiments and random seeds.
- Saving and loading trained models.
- Introduction to model versioning and experiment tracking.

## Practical

- Build a complete scikit-learn pipeline using a real dataset.
- Compare a baseline model against an improved model.
- Save the best model using joblib.
- Load the saved model and make predictions on new records.

## Outcome

Students can build a reproducible ML pipeline rather than a collection of disconnected notebook cells.
