# Day 23 — Deploying a Machine Learning Model

**Module:** Module 6: Modern ML and Project

## Theory

- Batch prediction vs. real-time prediction.
- Serving a model through a REST API.
- Model serialization and version compatibility.
- Training-serving consistency.
- Model drift, monitoring, and retraining.
- Security, privacy, and responsible deployment.

## Practical

- Load the trained model from Class 21.
- Create a simple prediction API using FastAPI.
- Accept input as JSON and return a prediction.
- Test the endpoint using Swagger UI or an HTTP client.
- Discuss how a frontend or another application could consume the API.

## Outcome

Students can expose an ML model through a simple API and understand the basics of production use.
